# 0.7 迁移收口清单

源代码基线：`08106b0c3771ef5b4a5aa176acccd460e88b7325`。目标是把这个版本已经实现的能力移植到 Python，并以 Vue 提供管理界面。此版本已补齐本次源码审计找到的功能缺口；下列适配约定是最终实现的一部分。测试覆盖具体场景，不是所有可能输入的数学证明。

## 原版到 Python 的适配约定

| 范围 | 最终约定 |
| --- | --- |
| UI 与协议 | Vue 代替终端 TUI；CLI JSON / Web SSE 包装和文案保留 Python 结构。原 CLI 本地查询的关键字段有差分证据，未承诺全部字符串逐字一致。 |
| 会话与任务 | SQLite 持久化代替多处内存注册表；导入原会话生成副本。任务 ID、路径和时间由新运行生成。Agent 工具等待真实结果，TaskCreate 返回后台任务。 |
| 文件与进程 | 工作区路径约束、密钥文件保护、输出预算、编辑唯一匹配、Notebook 清空旧执行输出均保留。Sleep 上限 60 秒；搜索最多扫描 5000 文件、返回 300 项。 |
| 搜索与 Git | grep 默认 content 并保留 Python numMatches 字段；工具输出同时提供原字段。Git 无差异返回空输出成功；原版 git_stdout 空输出报错不复制。 |
| REPL | Python 使用当前解释器，Bash/JS 单独启动进程。原 Windows `sh -lc command -v` 查找失败的夹具保留原错误，并单列 Python 成功结果。 |
| Config | 原偏好字段可保存；TUI 专用偏好保留数据，不虚构 Vue 中不存在的终端效果。原版也未接入的 autoDream 等字段不凭配置名宣称存在引擎。 |
| 网络 | Web 工具限制公网、固定解析后的地址并限制响应体；不自动跟随重定向。RemoteTrigger 返回 HTTP 错误状态，网络连接失败仍作为工具错误。 |
| MCP/LSP | Python 执行真实 MCP 资源读取和 LSP 请求；原版一些入口只返回注册表描述。无文件 LSP diagnostics 返回已有观察，明确标记 cached，不冒充新扫描。 |
| PDF/Lane | 保留原叶模块职责：PDF 是有限 literal/Flate 文本辅助函数，无 OCR；没有因为提示中出现 PDF 路径就自动读取。Lane 完成评估只返回条件和建议动作，不自动推送、合并或删会话。 |

## 原版未实现与外部条件

- 原目录有 140 个 slash 命令，36 个标记已实现。Python 有 115 个入口（含 17 个 Agent 提示工作流），剩余 25 个在原版也是占位；逐项见 [迁移矩阵](迁移矩阵.md)。占位项保留明确状态，不计作已实现功能。
- ACP、CCR 代理监听、MCP OAuth discovery/headersHelper/WS/SDK managed proxy 的完整执行器，不是该基线已经提供的功能。Python 不制造成功响应。
- 原 CLI 已移除 login/logout；Python 额外提供模型 OAuth PKCE/刷新、网页授权和 CLI 手工回调。真实本地 HTTP 协议测试已通过；未使用某家云厂商用户账号登录。现有 API Key 对话不受影响。
- PowerShell、各语言 LSP、gh、插件需要对应可执行程序和服务凭据。Python/pylsp 在应用镜像内；非 Python 语言服务器按项目安装。操作系统不提供的隔离会明确失败，Windows 无 Linux namespace，生产非特权容器不能嵌套 unshare。
- Git、模型、Qdrant 等服务不可用时返回实际错误。CI 验证不需要真实云密钥；线上模型/Qdrant 实测独立记录。

## 复现与学习

日常：`python -m pytest -q`、`ruff check backend scripts`、`ruff format --check backend scripts`、`npm --prefix frontend run build`。在项目虚拟环境运行，pytest 配置会加入 backend 路径。

原版差分：`scripts/verify_cli_local.py` 与 `scripts/verify_tool_contracts.py` 重新执行冻结 Rust，生成带 baseline 的固定预期；后者使用已缓存的离线 Cargo 依赖。夹具比较会排除生成路径、时长等不稳定值，两个已知适配在夹具中保留原值及理由。

最值得学习的新增代码是 `subagent_config` 与 `Tools.definitions(cfg)`：模型看到的工具列表和实际执行授权必须一致；子任务配置不能把父任务禁止的工具重新开放。其次看 `Sessions.delete` 的备份与活动检查、Cron 的执行计数、Worker 的“观察状态”和真实后台任务分离。总体数据流见 [架构设计](架构设计.md)，最终部署结果见 [部署验收记录](部署验收记录.md)。
