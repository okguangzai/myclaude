# 独立程序与模型路由

版本 0.7.0，目录 `C:\csg\work\project\myCalude`。这些程序均运行 Python，日常使用无需原 Rust 二进制。

## 四个程序入口

| 程序 | Windows 启动 | 作用 |
| --- | --- | --- |
| 主工作台 | `./start.ps1` | FastAPI 同时托管 Vue、聊天、扩展、任务与知识库 |
| 主 CLI | `./myclaude.ps1 -p "解释 README.txt"` | 无需 Web 服务，共享 Python runtime 和本机配置 |
| Lean Agent | `./analog.ps1 --workspace ./workspace --prompt "解释 README.txt"` | TOML 配置、窄工具集、文件会话、顺序运行多个 Agent |
| 工作区索引 | `./rag.ps1 ingest --workspace ./workspace` / `./rag.ps1 serve` | 独立增量索引与 HTTP 检索服务 |
| 测试模型 | `./mock-model.ps1 --bind 127.0.0.1:8788` | 12 个固定测试场景，不调用云模型 |

PowerShell 中请在上述项目目录运行这些命令。其它平台可安装 `backend/requirements.lock.txt`，设置 `PYTHONPATH=backend`，分别执行 `python -m app.cli`、`app.analog`、`app.rag_service`、`app.mock_service`。后端启动入口为 `backend/run_server.py`。Linux 宿主机 namespace/network 已实测；Windows 与生产非特权容器不支持该模式，会明确拒绝。

## 配置模型和备用连接

主工作台在「设置 → 对话模型」配置主模型；展开「模型故障切换」填写优先模型与备用模型。只需要一个对话模型就可以运行 Agent；Embedding 仅用于向量检索。没有新增“必须购买”的规划或审查专用模型。

备用模型连接例子：

```json
{
  "backup": {
    "provider": "anthropic",
    "base_url": "https://api.anthropic.com/v1",
    "api_key_env": "BACKUP_API_KEY",
    "model": "你的服务支持的模型 ID"
  }
}
```

在项目 `.env` 中自行填写 `BACKUP_API_KEY`，备用模型列表填 `backup`。前端只保存环境变量名；不会读回已保存的 Key。留空的密钥输入框表示保留后端当前值。原 `.env` 已保留，主配置保存在 `.local/settings.json`。

普通模型 ID 沿用当前连接。`opus`、`sonnet`、`haiku`、`grok`、`grok-mini`、`kimi` 是**冻结原仓库版本的别名**，并非实时推荐型号。带 `anthropic/`、`openai/`、`xai/`、`dashscope/`、`ollama/` 等前缀时可选择厂商连接：从对应 `ANTHROPIC_API_KEY`、`OPENAI_API_KEY`、`XAI_API_KEY`、`DASHSCOPE_API_KEY` 等变量取凭据，并支持同前缀 `*_BASE_URL`。本地 Ollama 支持 `OLLAMA_HOST`。不要把厂商前缀当成任意模型 ID 的必填部分。

顺序为显式 `provider_routes`、别名/厂商路由、当前默认连接。失败仅在响应尚未开始且错误可重试时切换；401/403、输出中断、已执行的工具不自动重放。

## 配置层和规则上下文

启动时依次读取用户 `.claw.json`、用户 `.claw/settings.json`、工作区 `.claw.json`、`.claw/settings.json`、`.claw/settings.local.json`，后者覆盖前者。`CLAW_CONFIG_HOME` 可指定用户配置目录。CLI 参数最后覆盖。读取只影响当前进程，不自动改写原设置文件。

已连接字段包括模型、provider、aliases、权限规则、默认权限、hooks、providerFallbacks、apiTimeout、rulesImport、trustedRoots、sandbox、插件目录和 MCP 配置。项目 `mcpServers` 支持 stdio/HTTP/SSE；无效条目保留诊断，有效的其它服务仍可使用。已接入原运行时功能字段、subagentModel 和公共偏好；未知/扩展字段不会静默忽略，`config inspect` 可查看来源和未映射项；显式 `config import` 在存在未映射项时拒绝保存。

```powershell
./myclaude.ps1 config inspect --output-format json
./myclaude.ps1 --cwd ./workspace --print-system-prompt --output-format json
./myclaude.ps1 bootstrap-plan --output-format json
./myclaude.ps1 --dump-manifests --output-format json
```

`prompt.py` 沿 Git 根目录到当前目录收集 AGENTS/CLAUDE/CLAW/MEMORY 文本和规则目录，可按 `rules_import` 导入 Cursor、Copilot、Windsurf 等规则。总读取长度有界，实际来源记录在 `context_loaded` 事件。

## 轻量 Agent

在工作区创建 `.claw-analog.toml`：

```toml
permission = "read-only"
preset = "explain"
stream = true
max_turns = 8
max_read_bytes = 262144
```

```powershell
./analog.ps1 config validate --workspace ./workspace
./analog.ps1 doctor --workspace ./workspace --skip-build
./analog.ps1 --workspace ./workspace --print-tools
./analog.ps1 --workspace ./workspace --session ./.local/lean-session.json --prompt "解释 README.txt"
./analog.ps1 agents --workspace ./workspace --agent audit --agent explain --split-sessions --prompt "分析 Agent 的工具边界"
./analog.ps1 complete powershell
```

同一路径的 `--session` 可继续历史；`--save-session` 可另存。工具限定为文件读取/列举/glob/grep/写入、只读 Git diff/log，以及显式配置的 RAG。默认审查与解释为只读，修改预设允许工作区写入。非交互危险模式需要显式 `--accept-danger-non-interactive`。`doctor --tcp-ping` 只做端口探测；默认编译检查对应 Python 语法检查，不执行 Cargo。

## 独立 RAG

此服务与网页上传知识库各自持久化。它保留原 Rust 的 `chunks`、`embeddings`、`files` 表布局和 little-endian float32 向量格式，使用 BLAKE3 检测变化。每次 ingest 的 workspace 集合代表该数据库的完整索引范围，遗漏的旧根目录和删除文件会移出索引。

先用无费用测试向量运行：

```powershell
$env:CLAW_RAG_MOCK_PROVIDERS = '1'
./rag.ps1 ingest --workspace ./workspace --db ./.local/learning-index.sqlite
./rag.ps1 serve --db ./.local/learning-index.sqlite
```

访问 `http://127.0.0.1:8787`、`/health`、`/v1/stats`；向 `/v1/query` POST `{"query":"Agent 循环","top_k":5}`。测试向量只用于验证流程，没有真实语义检索能力。

使用云向量时移除 `CLAW_RAG_MOCK_PROVIDERS`，设置 `CLAW_RAG_OPENAI_API_KEY`、`CLAW_RAG_EMBEDDING_BASE_URL`、`CLAW_RAG_EMBEDDING_MODEL`。可选 `CLAW_RAG_QDRANT_URL`、`CLAW_RAG_QDRANT_API_KEY`、`CLAW_RAG_QDRANT_COLLECTION`。这些是独立服务配置，不自动复用网页设置。Qdrant 不可用时查询可回退 SQLite；SQLite 与 Qdrant 不是分布式事务，镜像故障后需要重新验证同步状态。

## CLI 管道与本地恢复

`prompt` 子命令、`--stdin` / `--prompt-stdin`、`--compact` 和 `system-prompt` 入口已接入共享运行时。`CLAW_OUTPUT_FORMAT` 可设默认输出，命令行覆盖环境变量，大小写均接受。`--resume latest` 不带新请求时只读取已有会话，不调用模型。

```powershell
"补充上下文" | .\myclaude.ps1 --compact prompt "请总结" --stdin
.\myclaude.ps1 system-prompt --output-format JSON
.\myclaude.ps1 --resume latest --json
```
