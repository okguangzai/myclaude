## 0.4 新增的运行时集成

- Provider：首个输出前的重试和有序 fallback；环境凭据引用与已配置连接分开，缺少厂商凭据不跨发其它密钥。
- Prompt：从 Git 根到 cwd 发现指令与规则；共享 CLI/Agent 提示构建，记录上下文来源。
- 配置：五层启动覆盖和来源；CLI 参数最后覆盖；MCP 私密 env/header 不在公共接口中回传。
- Worker/Lane：preflight、启动证据与超时分类、信任拒绝优先、任务每 10 秒真实心跳、freshness、终态调和、commit/nudge 去重。
- Session：标准摘要和 Trident 三阶段整理，原子保留 assistant/tool 配对；自动摘要用于模型上下文，完整存储历史保留。
- MCP：连接/握手/发现/调用/关闭阶段证据，有限启动重试，部分发现失败显示 degraded；历史健康不冒充当前连接。
- 插件：bundled/external 目录发现、失败独立报告、同步与升级回滚、打包技能；唯一且无冲突的原工具名可作为兼容别名。
- 平台：Linux unshare 探测和 namespace/network 包装；Windows 明确不支持，文件系统隔离请求拒绝；CCR 描述符与已存在代理环境继承。
- 恢复：任务按 PID + 进程创建标识归属，Web 重启保留仍运行的 CLI 任务；旧无归属记录和死亡执行器才恢复为中断。
- Vue：备用模型、规则导入、追踪、插件目录与同步、Trident 选择、任务心跳展示。

## 原项目自身的边界

- 原 `acp` 是状态占位、退出码 2；Python 保持显式“不支持”的状态，没有伪造编辑器服务。
- `remote.rs` 的 CCR 部分是配置/环境描述模块，并没有实际代理监听器；Python 也不宣称启动了代理。
- Recovery recipes 的原模块是可注入执行器的仿真；诊断 API 明确返回 simulation，不自动 rebase 或合并。
- 原主 MCP 执行器支持 stdio；WS/SDK/managed proxy 描述不等于真实可连接传输。Python 额外实现 HTTP/SSE。
- 25 个占位 slash 命令、builtin 示例空插件不计作真正的引擎功能。

## 学习顺序

1. `providers.py → agent.py → extensions.py`：流式工具调用、协议归一、权限与副作用；用 12 场景测试观察完整闭环。
2. `sessions.py → trident.py → prompt_cache.py`：配对历史、压缩、请求指纹与缓存命中下降原因。
3. `jobs.py → process_owner.py → lanes.py`：并发、取消、心跳、重启恢复、状态证据。
4. `mcp_client.py → lifecycle.py → plugins.py`：连接所有权、发现降级、启动重试、插件升级回滚。
5. `rag_service.py`：增量索引、Embedding、SQLite/Qdrant 两种检索路径；先用 mock 向量理解数据流，再接云模型。
